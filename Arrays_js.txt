Arrays :- 
---------
It is an variable which allows to store multiple. 

Arrays are classified into two types
		1. Single Dimensional Array
		2. Double/Multi Dimensional Array

Single Dimensional Array :-  Values are arranged either in Single row / Single col

		let/var <variable> = [val1, val2, ....]

		let x = [10,20,30,40,50];

Double Dimensional Array :-  Values are arranged in mutiple rows and cols

		let/var <variable> = [[val1, val2, ....], [val3, val4, ...], ....];

		let  x = [[10,20,30],[40,50,60]];

push() :-  it allows to add values to the existing array at the ending position.
	array.push(val)
